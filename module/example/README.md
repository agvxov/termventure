# Example

> [!NOTE]
> This module is no interest to you unless you are a module developer.

This module demonstrates how to construct your own.

The directory structure is the minimum of what is expected.

**README.md**:
* short introduction for the module
* preferably without *spoilers*

**example.ini**:
* default configuration
* not touched by the user

**internal/**:
* helpers and encounters
* not exposed to the player

**user-action/**:
* scripts the player is expected to run to play
* in their PATH
